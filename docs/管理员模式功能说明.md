# 管理员模式功能说明

## 1. 功能概述

管理员模式是 `DiagnosticFlashTool.App` 内部的会话状态，用于在输入管理员密码后标记当前应用进程已进入管理员模式。

当前版本实现了以下能力：

- 通过密码弹窗校验管理员密码。
- 显示管理员模式的启用状态。
- 在全局状态栏和运行日志中记录认证结果。
- 仅在当前应用进程中保存启用状态，进程退出后自动失效。

当前版本尚未把管理员状态用于页面、字段或业务命令的访问控制。因此它目前是“认证及状态展示”功能，不能作为可靠的业务授权或安全边界。

管理员模式与 Windows 的“以管理员身份运行”无关，不会触发 UAC，也不会提升进程、文件或设备访问权限。

## 2. 功能入口

1. 启动 DiagnosticFlashTool。
2. 在左侧导航选择“系统设置”。
3. 在“基础设置”中找到“管理模式”开关。
4. 单击开关，打开“启动管理员模式”密码弹窗。

未启用时，开关处于关闭状态，右侧显示“未启用”；启用后，开关保持开启，右侧以成功状态样式显示“已启用”。

## 3. 密码规则

当前内置密码为：

```text
admin
```

密码使用区分大小写的完全匹配规则：

- `admin`：通过。
- `Admin`、`ADMIN`：不通过。
- ` admin`、`admin `：不通过。
- 空密码：不通过。

输入内容由 `PasswordBox` 使用掩码显示。当前代码不会自动修剪首尾空白，也没有错误次数限制、重试延迟或锁定机制。

该固定密码仅适合开发和测试环境。密码以明文常量存在于客户端代码中，不应作为生产环境的安全凭据。

## 4. 操作行为

| 当前状态 | 用户操作 | 结果 |
| --- | --- | --- |
| 未启用 | 单击“管理模式”开关 | 打开密码弹窗，密码框为空，显示本次启动内有效的提示 |
| 弹窗打开 | 单击“取消” | 清空密码并关闭弹窗，模式保持未启用 |
| 弹窗打开 | 在密码框内按 `Escape` | 与单击“取消”相同 |
| 弹窗打开 | 输入错误密码并提交 | 模式保持未启用，弹窗保持打开，密码被清空，显示错误提示 |
| 弹窗打开 | 输入正确密码并提交 | 启用管理员模式，清空密码并关闭弹窗 |
| 弹窗打开 | 在密码框内按 `Enter` | 提交当前密码 |
| 已启用 | 再次单击开关 | 关闭启动，退出管理员模式 |
| 已启用 | 切换应用内页面 | 管理员状态在同一进程中保持有效 |
| 已启用 | 隐藏到托盘后恢复 | 只要进程没有退出，管理员状态保持有效 |
| 已启用 | 完全退出并重新启动进程 | 管理员状态恢复为未启用，需要重新认证 |

错误密码提交后，弹窗提示由“请输入管理员密码，本次启动内有效。”更新为“密码错误，请重新输入。”。取消并重新打开弹窗后，恢复初始提示。

## 5. 状态与日志

### 5.1 认证成功

- `AdminModeEnabled` 设置为 `true`。
- 页面状态显示“已启用”。
- 全局状态更新为“管理员模式已启动”。
- 全局状态类型为 `Success`。
- 新增日志：`Admin mode enabled.`。

### 5.2 认证失败

- `AdminModeEnabled` 保持 `false`。
- 页面状态继续显示“未启用”。
- 全局状态更新为“管理员密码错误”。
- 全局状态类型为 `Warning`。
- 新增日志：`Admin mode password rejected.`。
- 密码原文不会写入认证日志。

当前日志级别分类器没有匹配上述两条英文日志的 `enabled` 或 `rejected` 关键词，所以它们在日志列表中可能被归类为中性级别；全局状态类型不受此问题影响。

## 6. 生命周期与持久化

管理员状态保存在 `MainViewModel` 当前实例的内存字段中，默认值为 `false`。

`settings.json` 不保存以下内容：

- 管理员模式是否已启用。
- 管理员密码。
- 认证失败次数。

关闭窗口到托盘不等同于退出进程。启用了后台运行时，从托盘恢复窗口后管理员状态仍然有效。只有完全结束应用进程并重新启动，才会恢复为未启用状态。

当前版本没有主动退出管理员模式、自动超时或锁屏后失效功能。

## 7. 当前权限边界

当前 `AdminModeEnabled` 只参与系统设置页面中开关和状态文案的显示，没有绑定到主导航或业务命令。

因此，无论管理员模式是否启用，以下现有入口当前都保持可见、可访问：

- 项目配置。
- 流程配置。
- 算法配置。
- 开发者选项。
- 系统设置中的运行配置、CAN 适配器和日志设置。

相关新增、编辑、删除、保存及诊断命令也没有检查管理员状态。仅隐藏导航按钮不足以形成权限控制；后续如引入权限限制，需要同时校验页面入口和实际业务命令。

在权限资源清单明确之前，不应对外宣称管理员模式能够保护配置或高风险诊断操作。

## 8. 实现位置

| 文件 | 相关内容 |
| --- | --- |
| `src/DiagnosticFlashTool.App/ViewModels/MainViewModel.cs` | 管理员状态、密码、提示文案、三个命令及密码校验逻辑 |
| `src/DiagnosticFlashTool.App/Views/SystemSettingsView.xaml` | 管理模式开关、状态样式、遮罩和密码弹窗 |
| `src/DiagnosticFlashTool.App/Views/Controls/PasswordBoxBinding.cs` | `PasswordBox` 与 ViewModel 密码属性的双向绑定 |
| `src/DiagnosticFlashTool.App/MainWindow.xaml` | 主导航与页面入口；当前未绑定管理员状态 |

主要 ViewModel 成员：

| 成员 | 作用 |
| --- | --- |
| `AdminModeEnabled` | 表示当前进程是否已启用管理员模式，只能由 ViewModel 内部设置 |
| `AdminModeStatusText` | 根据启用状态返回“已启用”或“未启用” |
| `AdminPasswordPromptVisible` | 控制密码遮罩及弹窗是否显示 |
| `AdminPassword` | 保存弹窗当前输入，提交或取消后清空 |
| `AdminPasswordMessage` | 显示初始提示或密码错误提示 |
| `ShowAdminPasswordCommand` | 未启用时打开密码弹窗；已启用时保持当前状态 |
| `SubmitAdminPasswordCommand` | 校验密码并处理成功或失败结果 |
| `CancelAdminPasswordCommand` | 清空输入并关闭弹窗 |
| `EnableAdminMode` | 使用完全匹配规则校验密码并更新状态、日志 |

## 9. 已知限制与后续要求

| 编号 | 当前限制 | 建议要求 |
| --- | --- | --- |
| ADM-LIMIT-001 | 管理员状态不控制任何业务资源 | 先定义页面、字段和命令级权限矩阵，再在入口和命令执行层同时校验 |
| ADM-LIMIT-002 | 密码以明文常量硬编码 | 使用可配置的认证服务和适合部署环境的安全凭据方案 |
| ADM-LIMIT-003 | 可以无限尝试密码 | 增加失败次数限制、指数退避或临时锁定，并保留审计记录 |
| ADM-LIMIT-004 | 启用后不能主动退出且不会超时 | 增加退出管理员模式、空闲超时和必要的会话失效策略 |
| ADM-LIMIT-005 | 认证日志被归为中性级别 | 为认证事件设置明确的成功、警告级别，避免依赖文本关键词猜测 |
| ADM-LIMIT-006 | 页面使用“管理模式”，弹窗使用“管理员模式” | 统一用户界面和文档术语 |
